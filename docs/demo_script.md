SmartAttend — 3-minute Demo Script (AI at Work)

Total length: 3:00

0:00–0:10 (Intro)
- Presenter: "Hi — we are Team <Name>. SmartAttend automates classroom attendance to save teacher time and surface at-risk students."

0:10–0:40 (Problem + Quick Context)
- Show teacher dashboard overview and state problem: manual marking, delays.
- "Teachers spend X minutes per class -- SmartAttend reduces that via automation."

0:40–1:10 (Start Session — Teacher)
- Demo: Teacher logs in → clicks 'Start Session' → selects subject → chooses 'Code' session
- Show generated code + QR and optional geofence
- Narration: "A teacher launches a session in under 10 seconds."

1:10–1:40 (Student Marks — Face Verification)
- Demo: Switch to student (or use student account) → Mark Attendance → Enter code / scan QR
- Face capture UI appears; TF.js runs in browser, verifies face, marks attendance
- Show success toast and notification flow

1:40–2:10 (Realtime Update & Analytics)
- Switch to teacher/admin dashboard → show live attendance update
- Open Analytics: low-attendance shortlist and anomaly flags
- Narration: "Within seconds, admin sees actionable alerts and prioritized students."

2:10–2:40 (Correction Workflow & Notification)
- Demo: Student files correction request → Teacher reviews and approves/rejects
- Show notification being sent to student and audit log entry

2:40–2:55 (Scalability & Security)
- Mention anomaly logging, rate-limiting, JWT auth, and plan to add Azure AI services

2:55–3:00 (Closing + Ask)
- "SmartAttend saves teacher time, improves accuracy, and surfaces at-risk students. We're seeking Azure credits and mentorship to scale this to multiple institutions."

Tips
- Use short, clear narration and live interactions (avoid slides during demo).
- Prepare test accounts ahead of time and ensure the server is running locally or on a deployed URL with credentials in the README.
